04Name the parts

Do not mix these up

Four names. One chain of events.

These words describe different things. Separating them gives every scikit-learn command a place.

General method

Algorithm

A general method for finding a useful pattern in data.

Python object

Estimator

The scikit-learn object, such as LinearRegression(), before it has seen your data.

→fit on training data
Data-specific result

Fitted model

The estimator after .fit(X, y). It can now make predictions.

Keep this sentence: an algorithm is the general method; an estimator is the scikit-learn object; a fitted model is that object after it has learned from your training data; a prediction is its output for new inputs.

05Check the result

Do not mark your own homework

Hold some data back.

A model can memorise training rows and look impressive without learning a useful pattern. Keep examples aside before fitting, then use them to check how the model handles unseen data.

Used while fitting

Training data

Known input-and-answer pairs go into fit(X_train, y_train).

Held back until later

Test data

Use these to estimate likely performance on new data.

Metrics: choose a measure that reflects the cost of mistakes. Regression often uses MAE or RMSE; classification may use precision, recall or F1.

Leakage: if held-back answers influence preparation or tuning too early, the final score is no longer a fair test.

06Use a pipeline

Not a final step

Keep preparation and modelling together.

Real data often needs preparation before a model can use it. A scikit-learn pipeline records the preparation and the model as one repeatable object.

Prepare

Fill missing values, scale numbers, or encode categories.

Fit the model

Learn from prepared training data and known targets.

Predict

Apply the same preparation to new input before predicting.

Why it matters: a pipeline stops you preparing training data one way and new data another way. It contains this part of the workflow; after testing, the whole pipeline can be saved.

07Read the code

The code follows the picture

One small, complete example.

This example has one input feature, study hours, and one known answer, exam score. The code follows the same construct → fit → predict pattern you have already seen.

# inputs X: study hours
# known answers y: exam scores
from sklearn.linear_model import LinearRegression

X = [[1], [2], [3]]
y = [2, 4, 6]

model = LinearRegression()
model.fit(X, y)
prediction = model.predict([[4]])

print(prediction)  # [8.]

Read down the code

  1. Import one specific estimator from scikit-learn.
  2. Set up three known input-and-answer pairs.
  3. Construct an unfitted estimator.
  4. Fit the learned relationship to the known pairs.
  5. Predict a score for four study hours.

When you meet a new scikit-learn class, ask:

Does it prepare data, learn from data, make a prediction, or measure a result? Then ask what input it expects and what it returns.
